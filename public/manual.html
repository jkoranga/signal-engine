⚡ Scan Modes
Choose what the scanner checks on each run.

Single SINGLE
Scans one symbol at a time — whichever is selected. Fast, focused. Good for monitoring one coin closely.
Tip: tap any symbol in the list to switch to it.

🔁 Loop Mode
🔁 What is Loop Mode?
Loop Mode makes the scanner run continuously back-to-back without waiting for the auto-interval timer. As soon as one full scan finishes, the next one starts immediately.

When to use it: When you want real-time continuous scanning during active market hours — e.g. scalping sessions or watching for breakouts.
▶
Normal Mode (Loop OFF)
Scanner runs once, waits for the interval (e.g. every 60s), then runs again. Easier on battery and data.
🔁
Loop Mode (Loop ON)
Scanner runs → finishes → immediately starts again. The loop counter shows how many full scans have run. Tap Loop again to stop.
⚠ Uses more data and battery. Best on WiFi with phone plugged in.
Loop + Single mode = watch one coin non-stop at maximum speed.

⏱ Timeframe Tabs
The bottom tab bar shows all timeframes: 1m 3m 5m 15m 30m 1h 4h Day

Each tab is independent — its own scan state, results, sort, filter, and pattern list. Switching tabs does not stop an active scan on another tab.

A green dot on a tab means that tab has active results.

⚙️ Settings — Scan Settings GLOBAL
📦
Symbol Set
How many coins to scan across all timeframes.
Top 30 fastest · Top 100 balanced · Top 200 wider · Top 500 comprehensive · All every coin (slow)
Start with Top 100. Increase only if you need wider coverage.
⏰
Scan Interval
How often the auto-scanner runs when Loop Mode is OFF.
Options: 30s 1m 2m 5m
Shorter interval = more frequent updates but more data usage.
🔕
Dedup Interval
Suppresses duplicate alerts for the same coin + pattern combination within a time window.
Example: 5m means if BTCUSDT already fired "Bull Flag" in the last 5 minutes, it won't alert again.
Set higher (15m–30m) to reduce noise. Set to 0 to see every single match.
📊
Volume Filter (Global)
Minimum 24h volume a coin must have to appear in results. Applies to all TF tabs.

Filter out weak signals by requiring a minimum number of conditions to pass.

🗂 Per-TF Pattern Settings IMPORTANT
This is where you control which patterns run on which timeframes.

Each of your patterns can be enabled or disabled per-scanner, and you can assign specific TFs to each pattern.

Example: Your "EMA20 Slope" pattern is only useful on 1h and 4h — disable it for 1m and 5m to keep scans fast and reduce noise.
✅
Enable / Disable per scanner
Toggle each pattern on/off for each scanner type (built-in scanners + your custom patterns).
⏱
TF selection per pattern
Choose which timeframes each pattern runs on: 1m 5m 15m 1h etc. A pattern only fires alerts on its assigned TFs.
Assign short TFs (1m/5m) to fast scalp patterns. Long TFs (4h/1d) to trend patterns.
No patterns for this TF? If you open a TF tab and see a warning, go to Settings → Pattern Settings and enable at least one pattern for that timeframe.
🔧 Pattern Builder PATTERNS
A Pattern is a named set of conditions that must all be true for a coin to fire a signal.

Think of it as: "Show me coins where ALL of these are true right now."

Every pattern has a side (Bull or Bear), a list of conditions, and a set of timeframes it runs on.
Example pattern — "EMA Bounce Bull"
① Close > EMA20  (price is above EMA20)
② EMA20 > EMA50  (short EMA above long EMA)
③ Close[-1] < EMA20[-1]  (previous candle was below EMA20)
④ RSI < 60  (not overbought)
→ Fires when price just bounced back above EMA20 with trend alignment.
📊 Fields — Left Side (LHS)
The Left Hand Side is what you're measuring on a candle. You also pick a candle offset like [0] Current or [-1] Prev 1.
GroupFieldsWhat it is
Price Close, Open, High, Low, Volume Raw candle data. Close is the current closing price.
EMA EMA5 → EMA600 Exponential Moving Average over N candles. EMA20 reacts faster than EMA200.
Indicators RSI, +DI, -DI, ADX RSI 14 = momentum 0–100. +DI/-DI/ADX = trend direction & strength.
Calc Change%, 24h%, Body%, Body Size, Range H-L, Upper Wick, Lower Wick, Is Green, Is Red Computed values from candle data. Most useful for candle-pattern conditions.
Candle Offset — [0] = current candle, [-1] = 1 candle back, [-2] = 2 candles back, up to [-10]. Use offsets to check what happened on previous candles.

➡️ Right-Hand Side (RHS) Modes
The Right Hand Side is what you're comparing against. Six modes:
🔢
Value NUMBER
A fixed number. Example: RSI > 50 or Volume > 1000000
📊
Field FIELD
Another candle field. Example: Close > EMA20 or EMA20 > EMA50
You can also pick a different candle offset for the RHS field.
✖️
× Multiplier MULT
Field × a multiplier. Example: Close > EMA20 × 1.02 means price is more than 2% above EMA20.
±
± Percent PCT
Field ± a percentage offset. Example: LWick > Body +25% means lower wick is longer than body by 25%.
📐
% Diff PCTDIFF
The % gap between left and right field. Example: how far Close is from EMA200 as a percentage.
📈
Slope % SLOPE
How much a field rose or fell over N candles, as %. Example: EMA10 slope >= 2% over 10 candles means EMA is rising steeply. See Slope section below.
🪟 Range Check — Candle Window
By default a condition checks only the current candle [0].

Enable Range Check to check the condition across a window of candles (e.g. last 5 candles), with two modes:
✅
ALL candles pass
Every candle in the range must satisfy the condition. Good for confirming a sustained trend.
Example: ALL[-1 to -5] Close > EMA20 → price was above EMA20 for the last 5 candles.
☑️
ANY candle passes
At least one candle in the range must satisfy the condition.
Example: ANY[-1 to -3] LWick > Body +25% → a wick-rejection candle appeared in the last 3 candles.
The range is defined as From offset → To offset, e.g. From [0] To [-4] = current + 4 previous candles = 5 candles total.
📐 Slope Mode (Trend Angle)
Slope % measures how much a field has risen or fallen over N candles as a percentage:

slope = (value[now] / value[N candles ago] − 1) × 100
📏
Slope Length (N)
How many candles back to measure from. Default 5. Larger N = smoother, less reactive. Smaller N = sharper, more reactive.
⏭
Slope Skip
Skip the most recent N candles before measuring. Skip=0 starts from the current candle. Skip=2 ignores the 2 most recent candles — useful to avoid false reads from the live forming candle.
%
Threshold %
The slope must be above (or below) this %. Positive = rising, negative = falling.
Example: EMA10 slope >= +2% over 10 candles = EMA is rising at least 2% across 10 candles = uptrend confirmed.
Bull slope condition: EMA10 >= Slope +2% (len 10, skip 0)
→ EMA10 has risen at least 2% over the last 10 candles = bullish momentum

Bear slope condition: EMA10 <= Slope −2% (len 10, skip 0)
→ EMA10 has fallen at least 2% over the last 10 candles = bearish pressure
⚡ Pattern Actions
⇄
Mirror
Creates an opposite copy of the pattern — flips Bull ↔ Bear, inverts all operators (> becomes <), flips High ↔ Low and LowerWick ↔ UpperWick. One-tap to create a matching bear pattern from a bull pattern.
After mirroring, review the conditions to make sure they make sense for the new side.
⧉
Copy
Duplicates the pattern with a new name. Same side, same conditions. Good for creating a variation without losing the original.
🔒
Lock
Locks the pattern to prevent accidental edits. A locked pattern can still scan — it just can't be modified until you unlock it. Tap the lock icon and confirm to unlock.
↑↓
Reorder (↑ ↓ arrows)
Move patterns up or down in the list. The order affects which patterns appear first in scan results.
🗑
Delete → Trash
Deleted patterns go to the Trash Bin (bottom of the page). They can be restored from there. Trash holds up to 50 patterns. Use Purge to permanently delete.
📤 Import / Export / Bulk Select
📤
Export
Download your patterns as a .json backup file. Two options when exporting selected patterns:
Combined — all selected patterns in one file
Individual — one separate .json file per pattern, named after the pattern
📥
Import
Load patterns from a .json backup file. Duplicate pattern names are automatically skipped to prevent overwriting existing patterns.
☑
Select Mode (bulk actions)
Tap ☑ Select to enter selection mode. Tap any pattern to select it (amber checkbox appears). Then use:
Export (N) — export selected patterns
Delete (N) — delete selected (requires confirm tap)
Use All / None buttons to select/deselect all at once.
Backup tip: Export all your patterns regularly and save the JSON file to Google Drive or Telegram Saved Messages as a backup.
